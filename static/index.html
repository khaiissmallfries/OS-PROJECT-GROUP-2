Deadlock Avoidance Architecture

Coffman Conditions Proof
Coffman Condition System Design Status
1. Mutual Exclusion Resources protected via Station & Vault Mutexes Enforced
2. Hold & Wait Runners request one station at a time. Stations do not request from each other. Prevented
3. No Preemption Only the lock holder can release the lock after completing atomic transfer. Enforced
4. Circular Wait Strict resource hierarchy: Vault Mutex → Station Mutex. Centralized Station D Banker. MATHEMATICALLY ELIMINATED

Because Station D is the sole entity that modifies station inventories and follows a strict hierarchical locking sequence, circular wait dependencies ($L_1 \rightarrow L_2 \rightarrow \dots \rightarrow L_1$) are impossible.
